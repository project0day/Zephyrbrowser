# Zephyr Bridge

Один файл, который превращает любого провайдера в постоянно доступную модель для Zephyr.

## Зачем

Пейринг через ntfy в Zephyr решает ровно одну задачу — **до телефона нельзя достучаться**.
У развёрнутого моста есть публичный адрес, значит задачи больше нет, и вся схема с
ретранслятором становится не нужна. Zephyr обращается к мосту так же, как к OpenAI.

```
Zephyr ──POST /v1/chat/completions──► мост (Vercel) ──► модель
                                                   ◄── ответ (потоком)
```

Ключ живёт на мосту, а не в телефоне. Меняешь его в одном месте — меняется на всех устройствах.

## Важно про serverless

Функция Vercel просыпается **на запрос** и умирает сразу после ответа. Она **не может**
висеть в цикле и слушать ntfy. Мост, написанный как «подписался и жду», отработает пару раз,
а потом тихо перестанет — и в логах всё будет выглядеть нормально.

Поэтому мост должен быть формы «запрос → ответ», как этот. Никаких циклов, никаких подписок.

## Развернуть

```bash
cd bridge
vercel env add BRIDGE_TOKEN     # секрет, который придумываешь сам
vercel env add UPSTREAM_URL     # адрес провайдера
vercel env add UPSTREAM_KEY     # ключ провайдера
vercel env add UPSTREAM_MODEL   # необязательно: жёстко закрепить модель
vercel deploy --prod
```

Проверить, что живой: открой `https://<app>.vercel.app/api/v1/chat/completions` в браузере —
должно вернуться `{"ok":true,...}`.

## Подключить в Zephyr

**Настройки → ИИ Помощник → Добавить модель**

| Поле | Значение |
|---|---|
| Endpoint | `https://<app>.vercel.app/v1/chat/completions` |
| Model | что ожидает провайдер (или что угодно, если задан `UPSTREAM_MODEL`) |
| Key | тот самый `BRIDGE_TOKEN` |

Дальше **Рой ИИ-агентов** → отметить мост в участниках.

## Несколько мостов

Разворачиваешь по проекту на провайдера — `bridge-glm`, `bridge-gemini`, `bridge-groq` —
и добавляешь все три в рой. Первый недоступен → отвечает второй, и ты этого не замечаешь.

## Про безопасность

`BRIDGE_TOKEN` обязателен. Без него любой, кто узнает URL, тратит твою квоту — адрес на Vercel
угадывается проще, чем кажется. Токен проверяется до обращения к провайдеру.
